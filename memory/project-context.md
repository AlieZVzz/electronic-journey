# 项目上下文

## 背景

Electronic Journey 帮助个人用户留存自己的工作、学习和创作过程。产品的差异化不是采集更多内容，而是在持续记录场景中保持知情、可见、可暂停、可撤销和端到端加密。

## 关键约束

- Windows 和 macOS 使用同一产品，但截图和系统安全存储由平台适配器实现。
- 默认每 5 分钟捕获，空闲 10 分钟后暂停，锁屏和休眠时不捕获。
- WebP 质量默认 85，最大宽度 2560 像素。
- 截图默认只以加密 `.ejourney` 文件保存。
- 云端只获得密文和最少量编排元数据。
- 本地写入与云端上传解耦，断网不得阻止本地保存。
- 第一阶段不做隐蔽运行、键盘记录、实时直播或服务端内容分析。

## 重要外部依赖

- macOS ScreenCaptureKit 与 Keychain。
- Windows.Graphics.Capture 与当前用户作用域 DPAPI。
- Tauri 2 runtime、capabilities 和 updater。
- SQLite、PostgreSQL 与 S3 兼容对象存储。

## 当前状态

仓库已完成初始化，但平台截图、系统安全存储和云同步仍是占位边界，不具备真实记录能力。
