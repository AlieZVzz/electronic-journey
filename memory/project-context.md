# 项目上下文

## 背景

Electronic Journey 帮助个人用户留存自己的工作、学习和创作过程。产品的差异化不是采集更多内容，而是在持续记录场景中保持知情、可见、可暂停、可撤销，并让用户主动选择本地图片上传到自己的服务器。

## 关键约束

- Windows 和 macOS 使用同一产品，但截图和系统安全存储由平台适配器实现。
- 默认每 5 分钟捕获，空闲 10 分钟后暂停，锁屏和休眠时不捕获。
- 本地原图使用无损 WebP 并保留平台捕获的像素尺寸；时间线缩略图最大宽度为 1440 像素，今日页显示最新原图。
- 新截图默认以普通 WebP 原图和缩略图保存在本机。
- 不建设自有图片云端、对象存储或服务端 LLM 中转。
- 本地截图与个人服务器上传解耦，上传失败不得阻止本地保存。
- 只有用户选择图片并确认后，Rust 客户端才通过 SFTP 上传到指定文件夹。
- 客户端不感知远端 Hermes、提示词、模型或图片消费者。
- 不做隐蔽运行、键盘记录或实时直播；自动同步默认关闭，只在用户显式开启后运行。

## 重要外部依赖

- macOS ScreenCaptureKit 与 Keychain。
- Windows.Graphics.Capture 与 Credential Manager。
- Tauri 2 runtime、capabilities 和 updater。
- SQLite、`russh`、`russh-sftp` 与系统钥匙串。

## 当前状态

macOS 原型已具备主动授权后的真实截图、普通 WebP 与缩略图原子写入、SQLite 时间线和启动索引恢复。个人 SFTP 配置、队列和手动上传进入第一期实现；Windows 捕获、系统状态监听与托盘仍待完成。
