# 重要决策记录

## 2026-07-30 - 托盘复用唯一记录状态机

- 决策：托盘只是 `RuntimeState` 的视图和控制入口，不拥有独立的运行/暂停状态，也不直接操纵截图任务。
- 同步：主窗口、托盘、系统事件、权限变化和截图失败都通过同一刷新路径更新托盘，并主动通知主 WebView。
- 权限：托盘只显示缓存的真实授权状态；无权限时打开主窗口和知情说明，不从快捷入口直接触发系统授权。
- 交互：运行或系统暂挂时可暂停或停止；暂停、停止、异常时可尝试开始，失败原因在聚焦的主窗口上以原生提示呈现。

## 2026-07-30 - 系统隐私条件覆盖记录意图

- 决策：分别保存用户记录意图和锁屏、休眠、空闲三个系统条件；系统条件只令有效状态暂挂，不替用户改变意图。
- 恢复：每个恢复事件只清除自己的条件，全部清除后等待 10 秒建立新调度，不追赶错过的截图；用户主动暂停或停止始终优先。
- 安全失败：平台监听或空闲查询不可用时停止记录并阻止重新开始，不能在系统隐私状态未知时继续捕获。
- 空闲策略：Rust 每秒读取系统最近输入时长；设置值 0 明确表示关闭空闲暂停。

## 2026-07-30 - 重复检测忽略受验证的系统边缘栏

- 决策：重复检测采用“完整像素摘要 + 平台系统栏稳定内容摘要”，不采用全屏感知哈希或全局相似度阈值。
- 原因：时间、网速等系统状态变化不应重复占用存储，但聊天新消息、弹窗或内容区单像素变化仍必须保存；明确的系统栏边界比全局近似相似度更可解释、可测试。
- 影响：去重排除区域只用于摘要，不修改保存的完整截图；平台几何或摘要不可用时保守退回完整像素比较。

## 2026-07-29 - 确定桌面系统最低版本

- 决策：macOS 最低支持 Sequoia 15，Windows 最低支持 Windows 11。
- Windows 实现：使用 `Windows.Graphics.Capture`、`IGraphicsCaptureItemInterop::CreateForMonitor` 和 D3D11 单帧回读，不维护 Windows 10 兼容分支。
- 影响：平台 API、权限流程和真机测试均可按上述最低版本设计；发布包仍需保留程序化图形捕获能力声明。

## 2026-07-28 - 采用 Tauri 2 与 Rust 核心

- 决策：桌面框架使用 Tauri 2，表现层使用 React/TypeScript/Vite，敏感核心使用 Rust。
- 原因：降低长期驻留资源占用，并将截图、密钥、文件和网络能力限制在可审计的 Rust 接口中。
- 替代方案：Electron、Avalonia、Flutter Desktop、双原生客户端。
- 影响：需要分别维护 ScreenCaptureKit 与 Windows.Graphics.Capture 适配层。

## 2026-07-28 - 浏览器开发模式不执行敏感能力

- 决策：普通 Vite 模式只提供本地演示状态。
- 原因：允许在 Rust 工具链不可用时验证 UI，同时不伪造截图、上传或删除成功。
- 影响：平台能力必须在 Tauri 真机环境中单独验收。

## 2026-07-28 - 项目级 Codex 配置不固定模型

- 决策：`.codex/config.toml` 设置推理、沙箱和文档发现规则，但不设置 `model` 或 `model_provider`。
- 原因：尊重用户当前默认模型；当前 Codex 文档也说明项目级配置不能覆盖 `model_provider`。
- 影响：不同开发者可能使用不同可用模型，但共享相同仓库安全边界和工作协议。

## 2026-07-28 - 前端不加载远程字体或图片

- 决策：初始 UI 仅使用系统字体和本地样式。
- 原因：避免桌面应用在无明确需要时产生第三方网络请求和隐私暴露。
- 影响：不同系统字体渲染会略有差异。

## 2026-07-29 - 改为个人服务器 SFTP 手动上传

- 决策：MVP 不建设产品方图片云、对象存储、云端时间线或 LLM 中转。图片默认只保存在本机；用户明确选择并确认后，由 Rust 客户端通过固定主机指纹的 SFTP 上传到其个人服务器文件夹。
- 原因：用户的远端环境已经具备后续处理能力，客户端只需提供可验证的文件交付边界。
- 客户端边界：不配置、不调用也不感知 Hermes、提示词、模型或其他远端消费者。
- 第一阶段：只支持单项勾选、全选当前已加载项和手动批量上传，不支持自动同步。
- 凭据约束：私钥通过系统原生文件选择器选择并验证为受限普通文件，私钥口令只保存在系统钥匙串。
- 本地格式：截图只使用普通 WebP 原图和缩略图，依赖系统账户权限以及可选的 FileVault/BitLocker；原型加密容器及其兼容分支已清理。
- 影响：需要 SQLite 上传队列、主机指纹核对、临时文件原子改名和逐项上传结果。

## 2026-07-29 - 增加显式选择加入的当天自动同步

- 决策：远程服务器配置新增独立自动同步开关，默认关闭；用户明确开启后，默认每 30 分钟同步当天尚未成功上传的原图，并支持 15、30、60、120、240 分钟间隔。
- 隐私边界：保存服务器配置、升级或迁移都不会自动开启；界面在开启时明确说明图片会离开设备。
- 安全失败：私钥、钥匙串、认证或固定主机指纹错误会暂停计划，必须重新保存配置或成功测试连接。
- 并发与恢复：手动与自动上传共享单活动批次；应用重启不重放中断请求，只在后续计划周期重新筛选。
