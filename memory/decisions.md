# 重要决策记录

## 2026-07-28 - 采用 Tauri 2 与 Rust 核心

- 决策：桌面框架使用 Tauri 2，表现层使用 React/TypeScript/Vite，敏感核心使用 Rust。
- 原因：降低长期驻留资源占用，并将截图、密钥、文件和网络能力限制在可审计的 Rust 接口中。
- 替代方案：Electron、Avalonia、Flutter Desktop、双原生客户端。
- 影响：需要分别维护 ScreenCaptureKit 与 Windows.Graphics.Capture 适配层。

## 2026-07-28 - 浏览器开发模式不执行敏感能力

- 决策：普通 Vite 模式只提供本地演示状态。
- 原因：允许在 Rust 工具链不可用时验证 UI，同时不伪造截图、上传或删除成功。
- 影响：平台能力必须在 Tauri 真机环境中单独验收。

## 2026-07-28 - 项目级 Codex 配置不固定模型

- 决策：`.codex/config.toml` 设置推理、沙箱和文档发现规则，但不设置 `model` 或 `model_provider`。
- 原因：尊重用户当前默认模型；当前 Codex 文档也说明项目级配置不能覆盖 `model_provider`。
- 影响：不同开发者可能使用不同可用模型，但共享相同仓库安全边界和工作协议。

## 2026-07-28 - 前端不加载远程字体或图片

- 决策：初始 UI 仅使用系统字体和本地样式。
- 原因：避免桌面应用在无明确需要时产生第三方网络请求和隐私暴露。
- 影响：不同系统字体渲染会略有差异。
