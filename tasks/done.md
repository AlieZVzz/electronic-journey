## 2026-07-29 - 个人服务器 SFTP 手动上传第一期

- 设计、架构、API、威胁模型和项目文案统一为“选择并确认后上传到个人 SFTP 文件夹”，客户端不感知 Hermes 或 LLM。
- SQLite 移除未启用的 AI 任务表，新增单一远程配置、上传批次和逐项状态；启动时将中断任务标记失败且不自动续传。
- 私钥通过系统原生文件选择器选择并验证为受限普通文件，口令只保存到系统钥匙串。
- SSH 连接固定 SHA-256 主机指纹，支持主动读取指纹、保存配置和远端目录写权限测试。
- SFTP 上传使用确定性日期路径、随机 `.part` 文件、写入确认、显式关闭、长度核对和原子改名；同名不同长度时拒绝覆盖。
- 时间线支持逐张勾选、全选当前已加载项、数量与大小确认、批量上传和最近状态展示。
- 活动上传阻止本地删除；上传结束后允许删除并保留不含图片内容的历史。
- 前端完整检查、Rust workspace 编译与测试通过；真实 SFTP 端到端仍需隔离测试服务器验收。

- 上传命令改为创建批次后立即返回，实际 SFTP 工作由 Rust 异步任务继续执行。
