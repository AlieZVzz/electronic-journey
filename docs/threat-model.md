# 威胁模型

## 需要防护

- LLM API 传输被窃听或篡改。
- API Key 或令牌从前端、SQLite、日志或普通配置文件泄露。
- 图片在未获用户确认时被自动或错误发送。
- endpoint 注入或跨域重定向导致图片和凭据发送到非预期目标。
- 前端 WebView 被攻陷后尝试读取任意本地文件或扩大系统权限。
- 路径遍历、软链接、超大文件和伪造图片格式。
- 日志、崩溃报告或分析事件意外泄露图片、问题或回答。
- 本地写入或 AI 请求的部分失败被错误显示为成功。

## 信任边界

- React WebView 是低信任表现层。
- Rust 核心进程可以接触短生命周期图片字节和 LLM 凭据。
- Keychain / DPAPI 是 LLM 凭据的持久信任根。
- SQLite 保存本地索引、AI 任务和非敏感设置，不保存明文凭据。
- 本地普通 WebP 受系统账户权限以及可选的 FileVault / BitLocker 保护。
- 用户选择的 LLM 提供商是外部数据处理方，会接收用户确认发送的图片和问题。
- 当前产品不包含自建图片服务器或对象存储。

## 不完全防护

- 用户已解锁且本机被恶意软件完全控制。
- 攻击者可读取应用进程内存或当前用户可访问的普通 WebP。
- 用户主动发送的图片包含密码、私钥或其他敏感内容。
- LLM 提供商按照其条款保留或处理已经接收的数据。
- 平台截图 API、系统 WebView 或 TLS 实现的未修复漏洞。

## 关键控制

- 最小 Tauri capability 和窄命令接口。
- 截图读取只接受 UUID，由 Rust 解析受控目录中的路径。
- 拒绝软链接、非普通文件、超大文件和未知图片格式。
- 原图和缩略图使用临时文件、刷新、原子重命名和回读解码验证。
- 单张删除只接受 UUID；先将受控目录内文件原子隔离，再事务删除 SQLite
  索引，失败时回滚文件名，并在返回成功前验证记录和文件均不存在。
- LLM 请求只允许内置适配器声明的 HTTPS 域名。
- 跨源重定向不得携带 Authorization header。
- 每次发送图片前显示图片、提供商、模型和目标域名并要求确认。
- 默认不自动重试图片请求，避免重复披露与重复计费。
- API Key 和令牌保存到 Keychain / DPAPI。
- 敏感值日志禁令和依赖锁定。

## 验证清单

- 前端无法调用未注册命令或访问任意文件路径。
- UUID 参数无法越权读取其他文件，软链接不会被跟随。
- 原图预览读取会核对 SQLite 中的文件大小和 SHA-256；WebView 解码失败不会显示为成功，也不会发送给 LLM。
- 删除仍被 AI 任务引用的截图会被拒绝；部分失败不会被界面显示为删除成功。
- 未经用户确认不会产生任何包含图片的外部请求。
- endpoint 注入、跨源重定向和模型返回内容不能改变请求目标。
- 删除凭据后不能创建新的提供商请求。
- 权限撤销、锁屏和休眠后不再产生截图。
- 日志扫描不包含图片、API Key、令牌、Authorization header、问题全文或完整回答。
