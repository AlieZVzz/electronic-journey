# 威胁模型

## 资产和边界

资产包括本地截图、采集时间、内容摘要、SSH 私钥与口令、远程配置、上传状态及应用更新签名私钥。React WebView 是低权限界面；Rust 核心可访问应用专用目录、SQLite、经验证的私钥路径、系统钥匙串和受固定公钥约束的更新器；个人 SFTP 服务器由用户管理；Hermes 或其他远端消费者完全位于客户端边界之外。

除用户配置的个人 SFTP 服务器外，应用只允许访问 Electronic Journey 官方 GitHub Release。检查更新必须由用户在“关于与更新”中主动触发；请求只获取公开的 `latest.json` 或用户确认版本对应的更新包，不发送截图、截图摘要、设备标识、远程配置或使用统计。应用不在后台静默检查或安装更新。

## 主要威胁与控制

| 威胁 | 控制 |
| --- | --- |
| 图片被自动或误上传 | 自动同步迁移和新配置默认关闭；独立开关与离机告知；手动上传仍需数量与大小确认 |
| 自动任务在错误身份上持续重试 | 每次固定主机指纹；私钥、钥匙串、认证或指纹错误会暂停计划，需重新保存或测试 |
| 休眠恢复后突发多个同步周期 | 调度器跳过错过的周期；同一时刻只允许一个上传批次 |
| 锁屏、休眠或用户长时间离开时仍然截图 | Rust 平台监听将记录切换为 `suspended` 并使待执行调度失效；全部条件解除后等待 10 秒恢复，不补拍错过周期 |
| 唤醒与解锁事件乱序导致过早恢复 | 锁屏、休眠和空闲条件分别保存；任一条件仍存在时禁止恢复 |
| 平台活动监听失效后继续记录 | 监听安装或空闲查询失败时采用安全失败：清除记录意图、取消调度并显示错误，重新启动前不能开始记录 |
| 托盘状态与实际截图状态不一致 | 托盘不缓存独立业务状态；所有文字和操作可用性均从 Rust `RuntimeState` 派生，状态变化同时刷新托盘和主窗口 |
| 从托盘绕过知情授权直接请求截图权限 | 无权限时托盘不调用系统授权接口，只打开主窗口并提示用户先阅读访问说明和明确确认 |
| 自动与手动上传重复同一图片 | 事务性单活动批次；自动筛选排除 `pending`、`uploading` 和任一成功记录 |
| SSH 中间人 | 保存并逐次比较 SHA-256 主机指纹；不提供跳过选项 |
| 前端读取任意本地文件 | 只接受截图 UUID；Rust 从 SQLite 和受控目录解析 |
| 前端写任意远端路径 | 相对路径由采集时间和 UUID 生成，拒绝 `..` 和绝对输入 |
| 私钥或口令泄露 | 私钥通过原生选择器明确选择并验证为受限普通文件；口令只存系统钥匙串；使用后清零 |
| 覆盖远端既有文件 | 同名不同长度时失败；先写随机 `.part` 后原子改名 |
| 中断留下成功假象 | 写入和改名后分别核对长度，才标记 `uploaded` |
| 日志泄露 | 禁止图片、摘要、凭据、完整远端路径和响应正文进入日志 |
| GitHub Release 或传输链路被篡改 | 更新包必须通过编译进应用的 Tauri 更新公钥验证；签名失败不得安装，私钥只保存在发布环境和维护者离线备份中 |
| 恶意或损坏的 `latest.json` 诱导安装任意程序 | 清单只决定候选版本和下载地址；Rust 更新器仍对完整下载内容做签名验证，且安装前再次核对用户确认的版本 |
| 更新请求泄露本地活动 | 只有用户点击后才发起固定 GitHub HTTPS 请求，不附加截图、账户、设备 ID 或自定义追踪头 |
| 更新与截图或上传并发造成中断 | 安装开始后拒绝新截图、手动上传和自动同步；存在活动上传时拒绝安装，停止截图后才替换应用 |
| 未做操作系统代码签名造成发布者警告 | UI 与 README 明确披露 macOS Gatekeeper / Windows SmartScreen 可能警告；Tauri 更新签名不冒充 Developer ID、notarization 或 Authenticode |
| 上传影响本地记录 | 上传和截图状态隔离；失败不修改本地图片 |
| 删除与上传竞态 | `pending/uploading` 项事务检查阻止本地删除 |
| 去重掩码过大导致重要内容未保存 | 只接受贴边、互不重叠且厚度不超过对应屏幕尺寸 10% 的平台系统栏；异常或缺失时退回完整像素精确比较 |

SFTP v3 的通用接口不提供远端 SHA-256。本期依赖本地 SHA-256 校验、SSH 传输完整性、远端长度和原子改名；不声称进行了远端内容摘要验证。

## 更新信任与剩余风险

Tauri 更新公钥可以公开并编译进客户端；对应私钥不得进入源码、构建日志、Release 或 workflow artifact。丢失私钥会使已安装客户端无法验证后续更新，因此维护者必须保留独立安全备份。

当前版本没有购买 Apple Developer ID 或 Windows Authenticode 证书。更新包的 Tauri 签名可以验证项目级来源和完整性，但操作系统仍可能阻止、隔离或警告安装；这属于已知发布限制，不得在 UI、README 或 Release 中声称安装包已获操作系统信任。
