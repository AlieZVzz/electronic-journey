# 威胁模型

## 资产和边界

资产包括本地截图、采集时间、内容摘要、SSH 私钥与口令、远程配置及上传状态。React WebView 是低权限界面；Rust 核心可访问应用专用目录、SQLite、经验证的私钥路径和系统钥匙串；个人 SFTP 服务器由用户管理；Hermes 或其他远端消费者完全位于客户端边界之外。

## 主要威胁与控制

| 威胁 | 控制 |
| --- | --- |
| 图片被自动或误上传 | 默认无外发；勾选、数量与大小确认；无自动上传任务 |
| SSH 中间人 | 保存并逐次比较 SHA-256 主机指纹；不提供跳过选项 |
| 前端读取任意本地文件 | 只接受截图 UUID；Rust 从 SQLite 和受控目录解析 |
| 前端写任意远端路径 | 相对路径由采集时间和 UUID 生成，拒绝 `..` 和绝对输入 |
| 私钥或口令泄露 | 私钥通过原生选择器明确选择并验证为受限普通文件；口令只存系统钥匙串；使用后清零 |
| 覆盖远端既有文件 | 同名不同长度时失败；先写随机 `.part` 后原子改名 |
| 中断留下成功假象 | 写入和改名后分别核对长度，才标记 `uploaded` |
| 日志泄露 | 禁止图片、摘要、凭据、完整远端路径和响应正文进入日志 |
| 上传影响本地记录 | 上传和截图状态隔离；失败不修改本地图片 |
| 删除与上传竞态 | `pending/uploading` 项事务检查阻止本地删除 |

SFTP v3 的通用接口不提供远端 SHA-256。本期依赖本地 SHA-256 校验、SSH 传输完整性、远端长度和原子改名；不声称进行了远端内容摘要验证。
