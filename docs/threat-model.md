# 威胁模型

## 需要防护

- 传输被窃听或篡改。
- 服务端数据库、对象存储或运维权限泄露。
- 本地或云端密文被替换、截断或损坏。
- 前端 WebView 被攻陷后尝试扩大系统权限。
- 日志、崩溃报告或分析事件意外泄露敏感信息。
- 上传、删除和恢复流程的部分失败造成错误成功状态。

## 信任边界

- React WebView 是低信任表现层。
- Rust 核心进程可以接触短生命周期明文和密钥。
- Keychain / DPAPI 是本地主密钥的持久信任根。
- SQLite 保存本地索引和非敏感设置，不保存明文密钥或令牌。
- 控制面 API、PostgreSQL 和对象存储一律视为不可信明文环境。

## 不完全防护

- 用户已解锁且本机被恶意软件完全控制。
- 攻击者可读取应用进程内存。
- 用户导出的明文被其他程序访问。
- 用户同时失去全部授权设备和恢复密钥。
- 平台截图 API 或系统 WebView 的未修复漏洞。

## 关键控制

- XChaCha20-Poly1305 认证加密和每文件随机数据密钥。
- 文件格式版本、记录 ID 和密钥版本进入 AAD。
- 最小 Tauri capability 和窄命令接口。
- HTTPS、短期令牌、单对象短时预签名地址。
- 原子本地写入、SQLite 事务和启动恢复扫描。
- 服务端对象存在性、大小和摘要回查后才确认上传完成。
- 敏感值日志禁令和依赖锁定。

## 验证清单

- 修改任意密文字节后解密失败且不返回部分明文。
- 错误主密钥、AAD 或记录 ID 均无法解密。
- 前端无法调用未注册命令或访问任意文件路径。
- 权限撤销、锁屏和休眠后不再产生截图。
- 日志扫描不包含密钥、令牌、URL、窗口标题和图片内容。
- 撤销设备无法申请上传或下载地址。
