# AI 协作手册

## 开始任务

1. 阅读根目录 `AGENTS.md`。
2. 阅读 `tasks/in-progress.md` 和相关长期文档。
3. 检查工作区状态，保留用户已有改动。
4. 对安全敏感改动先写简短方案和验证计划。

## 实现节奏

1. 找到现有边界和相邻实现。
2. 选择能满足验收标准的最小改动。
3. 使用类型和校验表达安全约束。
4. 补充最小相关测试。
5. 先运行局部检查，再运行 `scripts/check.sh`。
6. 更新任务、决策或经验文档。

## 完成报告

必须说明：

- 修改了什么。
- 实际运行了哪些检查以及结果。
- 哪些检查因平台或工具缺失未运行。
- 哪些能力仍是骨架或占位实现。
- 后续安全或产品决策。

## 禁止的成功表述

以下状态没有验证证据时不得声称成功：

- 已获得截图权限。
- 截图已保存。
- 加密或恢复可用。
- 对象已上传或删除。
- 服务端无法读取数据。
- Windows 与 macOS 均可运行。
